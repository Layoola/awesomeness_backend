# Awesomeness Backend

Minimal Node + TypeScript + Express boilerplate.

Getting started

1. Install dependencies

```bash
npm install
```

2. Run in development (auto-reloads on change)

```bash
npm run dev
```

3. Build and run

```bash
npm run build
npm start
```

Health check

GET `/api/health` -> { status: 'ok', timestamp: '...' }
